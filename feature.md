# Nova WebOS — Feature Matrix & Application Catalog

Nova WebOS comes pre-loaded with a comprehensive suite of 12 native applications, desktop multitasking controls, procedural audio generators, and cybernetic personalization tools.

---

## 1. Native Application Suite (12 Apps)

### 1. Nova AI Assistant (`assistant.ts`)
- **Natural Language Interaction**: Conversational AI companion equipped with contextual knowledge of Nova WebOS.
- **Autonomous System Actions**: Opens applications, checks hardware metrics, creates notes, and changes system themes based on conversational commands.
- **Pre-set Query Library**: Fast-action pills for checking system health, scheduling tasks, and generating creative ideas.
- **Code & Markdown Rendering**: Formats code snippets, lists, and markdown text cleanly.

### 2. Cybernetic Terminal CLI (`terminal.ts`)
- **UNIX-like Shell**: Interactive command line interface with simulated environment paths (`/home/user$`).
- **Command Set**:
  - `help` — Lists all registered commands.
  - `ls`, `cd`, `pwd`, `cat`, `mkdir`, `touch`, `rm` — Interacts directly with the Virtual File System.
  - `ai <prompt>` — Queries Nova AI directly from stdout.
  - `neofetch` — Displays cybernetic ASCII architecture and kernel specs.
  - `matrix` — Launches interactive green digital rain streams.
  - `clear` — Clears terminal history.
  - `theme <name>` — Live theme switching from the command line.

### 3. Virtual File System Explorer (`files.ts`)
- **Hierarchical Navigation**: Browse directories (`/root`, `/home`, `/apps`, `/system`).
- **File Management**: Create files, create folders, inspect file sizes, delete files, and view timestamps.
- **File Previews**: Built-in inspector for viewing text documents, configuration scripts, and system logs.

### 4. System Dashboard & Hardware Telemetry (`dashboard.ts`)
- **Realtime Gauges**: Visual circular and linear gauges for CPU Synapse load, RAM consumption, and VFS storage allocations.
- **Process Manager**: Lists active processes with their Process ID (PID), memory footprints, and one-click process termination.
- **Network & Kernel Telemetry**: Live ping latency, system uptime counter, and kernel diagnostics.

### 5. Dev Logs Journal (`devlogs.ts`)
- **System Audit Trail**: Live streaming audit logs showing system boot status, window focus changes, VFS operations, and error reports.
- **Filter by Severity**: Toggle between `ALL`, `INFO`, `SUCCESS`, `WARN`, and `ERROR` logs.
- **Log Export & Clear**: Export logs to local disk or clear the active buffer.

### 6. Notes & Document Editor (`notes.ts`)
- **Rich Document Management**: Create, edit, and organize multiple markdown documents.
- **Live Autosave**: Auto-persists notes to persistent storage to prevent data loss.
- **Search & Word Counter**: Real-time word, character, and line count telemetry.

### 7. Calendar & Event Scheduler (`calendar.ts`)
- **Interactive Calendar Grid**: Month view with day-by-day navigation, current date highlighter, and event markers.
- **Event Planner**: Add custom reminders, schedule operational tasks, and view scheduled agendas.
- **Task Timeline**: Chronological event list with deletion and status toggles.

### 8. Procedural Music Synthesizer (`music.ts`)
- **Polyphonic Web Audio Engine**: Interactive playable keyboard with keyboard keybindings (`A`, `S`, `D`, `F`, `G`, `H`, `J`).
- **Procedural Ambient Generator**: Generates evolving ambient space synth loops with custom tempo and scale selection.
- **Realtime Audio Visualizer**: Oscilloscope canvas visualizing audio frequencies in real-time.

### 9. Quantum Calculator (`calculator.ts`)
- **Dual Computation Modes**: Standard arithmetic calculator and Scientific mode (trigonometry, powers, square root, logarithms).
- **Calculation History Tape**: Audit trail of previous equations with one-click result copying.

### 10. Alarm, Stopwatch & Timer (`alarm.ts`)
- **High-Precision Stopwatch**: Millisecond-accurate lap timer with split records.
- **Customizable Countdown Timer**: Preset quick timers (1m, 5m, 15m, 30m) with audio chimes upon completion.
- **Multiple Alarms**: Set scheduled alarms with harmonic audio notifications.

### 11. Nova Web Browser (`browser.ts`)
- **Cybernetic Proxy Browser**: In-app web viewer with address bar, back/forward buttons, refresh, and bookmark manager.
- **Curated Bookmarks**: Pre-loaded tech news, documentation, and tools.
- **Source Inspector**: Inspect simulated DOM and response headers.

### 12. Personalization & Settings (`settings.ts`)
- **5 Cyber Themes**: Instant switching between Cyberpunk, Obsidian, Aurora, Matrix, and Solar.
- **Live Wallpaper Engine**: Particle flows, cyber grid, starfield, and waves.
- **System Preferences**: Adjust audio master volume, clock format (12h/24h), sound effects, and desktop widgets.
- **Factory Reset**: Restore system to default factory state with one click.

## 2. Desktop Environment & Multitasking Capabilities

- **Category-Organized Shelves**: Apps grouped into *Core System & AI Hub*, *Productivity Suite*, and *Tools & Cyber Media*.
- **Desktop Search Bar**: Instant real-time app filtering across all shelves.
- **Holographic Chrono Widget**: Live clock, localized date, and fluctuating CPU/RAM hardware meters.
- **Nova AI Command Widget**: Instant prompt input and quick-launch command pills.
- **Sticky Scratchpad Widget**: Desktop scratchpad with zero-latency autosave and direct export to Notes.
- **Desktop Context Menu**: Right-click menu for opening apps, personalizing themes, and refreshing the desktop.

---

## 3. Persistent Taskbar & System Tray

- **Dedicated Bottom Bar (`z-[9990]`)**: Persistent dock that remains visible underneath floating windows.
- **Start Menu Hub**: Full-screen application launcher with live search, category tabs, and user profile header.
- **Taskbar Dock**: Visual indicators for running, active, and minimized applications with hover tooltips.
- **Audio & Control Tray**: Master volume slider, mute toggle, procedural harmonic test chime, and quick theme palette.
- **Quick Peek Strip**: Single-click button to minimize all open windows and reveal the desktop.

---

## 4. Procedural Web Audio Capabilities

All sound effects in Nova WebOS are generated synthetically using the browser's Web Audio API:
- **Window Sound Effects**: Micro-frequency sweeps on window open, close, and maximize.
- **Audio Feedback**: Subtle click blips on button clicks and focus events.
- **Harmonic Boot Chime**: 4-note ascending chord progression on OS startup.
- **Alert Chimes**: High-frequency dual-tone pulses on timer completions and system warnings.
- **Zero Asset Dependencies**: Works 100% offline without external MP3/WAV files.
